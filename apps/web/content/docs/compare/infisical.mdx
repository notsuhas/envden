## The difference

Infisical is a secrets manager. It stores keys and values, not files, so the comments, order and blank lines of an env file are lost.

envden syncs the whole env file, byte for byte.

## What envden is

- For one person's own machines. v1 has no team sharing.
- Self-hosted only, on a server you run.
- End-to-end encrypted. The server holds ciphertext only.
- Reached over Tailscale.

## When envden isn't the fit

envden v1 doesn't share secrets with a team. If you need that, a secrets manager is the right tool.
