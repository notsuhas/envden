## The overlap

DotVeil is a small CLI that syncs env files, like envden.

## What envden is

- Syncs whole env files, byte for byte, across your own machines.
- Self-hosted only, on a server you run. The server holds ciphertext only.
- Built on pinned, published crypto libraries, with its protocol written down in `PROTOCOL.md` and reviewed separately before release.
- Reached over Tailscale.
