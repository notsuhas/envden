## Start setup

[Install the CLI](/docs/getting-started) and connect to Tailscale. Enable HTTPS certificates for your tailnet, then run:

```sh
envden setup --host-server
```

This installs a login service using launchd on macOS, systemd on Linux or a Windows login service, and publishes it on your tailnet with Tailscale Serve. Setup reads the server's setup token itself, so there's nothing to paste.

Choose a master password and save the recovery kit. Setup then lists the checkouts it found, all selected; press Enter to sync them or Space to leave one out. It places their files, pushes them and prints a summary.

Running `envden setup` without `--server` also offers to host the server on this machine.

## Work while offline

Your env files stay on disk when the server is unreachable. Other devices can sync only while this laptop is awake and reachable over Tailscale.

Use `envden status` to check the connection. An unreachable server shows as `Server: unreachable (connection refused)`, or with another reason.

## Move the server later

Start a server on your always-on host, then use [server move](/docs/server#moving-the-server). Your vault and device memberships move with it.
