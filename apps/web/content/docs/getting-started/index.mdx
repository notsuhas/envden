## What you need

- A Tailscale tailnet with HTTPS certificates enabled. Setup checks this.
- A machine to run the server: a home-lab host, or one of your own devices.

## Pick a path

- **[Home lab first](/docs/getting-started/home-lab-first).** The server runs in Docker on an always-on host. Setup recommends this.
- **[Laptop first](/docs/getting-started/laptop-first).** The server runs on your laptop as a login service. You can move it to an always-on host later.

Two laptops only sync while the laptop running the server is awake, which is why an always-on host is the recommendation.

## Install channels

The CLI will ship through Homebrew, a `curl | sh` script, an `irm | iex` script for PowerShell, npm, winget and Scoop. The server image will be on GHCR, and [Home lab first](/docs/getting-started/home-lab-first#1-run-the-server) shows how to run it.

The `curl | sh` and `irm | iex` scripts check the binary against `SHA256SUMS` over HTTPS. They don't check the signed release feed.
