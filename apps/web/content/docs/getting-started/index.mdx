## Install the CLI

Choose one method. The CLI runs on macOS, Linux and Windows.

### macOS and Linux

```sh
curl -fsSL https://envden.theclau.de/install.sh | sh
```

### Windows PowerShell

```powershell
irm https://envden.theclau.de/install.ps1 | iex
```

These scripts check the binary against `SHA256SUMS` over HTTPS. They don't verify the signed release feed. Later script-installed updates through `envden update` verify that feed.

### Homebrew

```sh
brew install notsuhas/tap/envden
```

### npm

```sh
npm i -g envden
```

### Scoop

```powershell
scoop bucket add envden https://github.com/notsuhas/scoop-bucket
scoop install envden
```

Check the installation:

```sh
envden version
```

For v0.1.0, this prints:

```text
0.1.0
```

## Choose a server

Your devices need Tailscale, with HTTPS certificates enabled for the tailnet. Setup checks this.

- [Home lab first](/docs/getting-started/home-lab-first): run `ghcr.io/notsuhas/envden` in Docker on an always-on host.
- [Laptop first](/docs/getting-started/laptop-first): run the server as a login service on this machine.

Use an always-on host if you have one. Other devices can sync with a laptop server only while that laptop is awake.

## For contributors

To build the CLI from source, install Bun 1.4 and run:

```sh
git clone https://github.com/notsuhas/envden.git
cd envden
bun install
bun run --cwd apps/cli build
./apps/cli/dist/envden --help
```

The compiled binary includes `envden serve`.
