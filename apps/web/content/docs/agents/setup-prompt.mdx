## What you still do yourself

The agent stops and hands these to you:

- Typing the master password.
- Reading or typing a pairing code.
- Approving each checkout before it receives env files.
- Keeping the recovery kit.
- Resolving conflicts.

See [Agents](/docs/agents) for the rules behind this.
