## envden agent

Install the envden agent skill.

```sh
envden agent [options] [command]
```

Subcommands: [`install`](#envden-agent-install).

## envden agent install

Install or refresh the agent skill.

```sh
envden agent install [options]
```

## envden alias

Share another repo's env files, for example from a fork.

```sh
envden alias [options] <repo> <target>
```

| Argument   | Description                     |
| ---------- | ------------------------------- |
| `<repo>`   | Repo ID to alias                |
| `<target>` | Repo ID whose env files it uses |

## envden config

Read or change settings.

```sh
envden config [options] [key] [values...]
```

| Argument      | Description                                                                                         |
| ------------- | --------------------------------------------------------------------------------------------------- |
| `[key]`       | telemetry, update-check, agent-merge, auto-approve-worktrees, unlock-period, placement or env-files |
| `[values...]` | New value; placement takes a checkout path and link or copy                                         |

## envden device rm

Remove a device and re-key the vault so it can't read new changes.

```sh
envden device rm [options] <device>
```

| Argument   | Description       |
| ---------- | ----------------- |
| `<device>` | Device name or ID |

| Option             | Description                                          |
| ------------------ | ---------------------------------------------------- |
| `--kit-out <file>` | Write the new recovery kit to a private file         |
| `--new-kit`        | Also replace the recovery kit as part of the removal |

## envden history

List the versions the server keeps, or restore one as a local edit.

```sh
envden history [options] [file]
```

| Argument | Description   |
| -------- | ------------- |
| `[file]` | Env file path |

| Option                | Description                                          |
| --------------------- | ---------------------------------------------------- |
| `--all`               | Include every tracked file                           |
| `--restore <version>` | Write that version into the checkout without pushing |
| `--yes`               | Confirm the restore                                  |
| `--json`              | Print the result as JSON                             |

## envden join

Join using a pairing code or recovery kit in your own terminal.

```sh
envden join [options] <server>
```

| Argument   | Description                                     |
| ---------- | ----------------------------------------------- |
| `<server>` | Server address, e.g. envden.your-tailnet.ts.net |

| Option                    | Description                                                       |
| ------------------------- | ----------------------------------------------------------------- |
| `--recovery`              | Paste a recovery secret key and vault ID                          |
| `--recovery-kit <path>`   | Recovery kit path                                                 |
| `--name <name>`           | Device name                                                       |
| `--yes`                   | Use default preferences                                           |
| `--telemetry <choice>`    | Anonymous telemetry (on, off)                                     |
| `--update-check <choice>` | Daily update check (on, off)                                      |
| `--shell <shell>`         | Shell notice (zsh, bash, fish, powershell, none)                  |
| `--agent <choice>`        | Install the agent skill (on, off)                                 |
| `--resume`                | Finish a join that was approved while this command wasn't running |

## envden serve

```sh

```

| Option                   | Description                                 |
| ------------------------ | ------------------------------------------- |
| `--restored`             | Start a restored backup in repair-only mode |
| `--min-client <version>` | Oldest client version to accept             |
| `--data-dir <path>`      | Server data directory                       |

## envden server

Move, switch or repair the server.

```sh
envden server [options] [command]
```

Subcommands: [`move`](#envden-server-move), [`repair`](#envden-server-repair), [`switch`](#envden-server-switch).

## envden server move

Move the vault to a new server.

```sh
envden server move [options] [server]
```

| Argument   | Description                |
| ---------- | -------------------------- |
| `[server]` | Destination server address |

| Option                  | Description                                                           |
| ----------------------- | --------------------------------------------------------------------- |
| `--setup-token <token>` | Setup token, visible to other processes; use the prompt in a terminal |
| `--resume`              | Resume an interrupted move                                            |
| `--abort`               | Abort an unfinished move                                              |

## envden server repair

After a server restore, re-upload this device's data, or finish the restore with --finish.

```sh
envden server repair [options]
```

| Option                   | Description                                                        |
| ------------------------ | ------------------------------------------------------------------ |
| `--repair-token <token>` | Repair token; prefer stdin for upload, use a terminal for --finish |
| `--finish`               | Check every device's upload and finish the restore                 |
| `--without <device...>`  | Drop unavailable devices; they rejoin as new devices               |
| `--accept-lost`          | Accept the newest verified older version of a missing file         |

## envden server switch

Follow a signed move when the old server is unreachable.

```sh
envden server switch [options] <server>
```

| Argument   | Description                |
| ---------- | -------------------------- |
| `<server>` | Destination server address |

## envden setup

Create a vault and configure this device.

```sh
envden setup [options]
```

| Option                     | Description                                                              |
| -------------------------- | ------------------------------------------------------------------------ |
| `--yes`                    | Take defaults; secrets and checkout approval still require your terminal |
| `--server <url>`           | Use this server                                                          |
| `--kit-out <file>`         | Write recovery kit to a private file                                     |
| `--name <name>`            | Device name                                                              |
| `--host-server`            | Run the envden server on this machine; no setup token needed             |
| `--setup-token <token>`    | Setup token, visible to other processes; use the prompt in a terminal    |
| `--telemetry <choice>`     | Anonymous telemetry (on, off)                                            |
| `--update-check <choice>`  | Daily update check (on, off)                                             |
| `--shell <shell>`          | Shell notice (zsh, bash, fish, powershell, none)                         |
| `--agent <choice>`         | Install the agent skill (on, off)                                        |
| `--scan-root <path...>`    | Roots to scan for repos                                                  |
| `--exclude-root <path...>` | Roots to skip                                                            |
