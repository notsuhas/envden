Join using a pairing code or recovery kit in your own terminal

Usage: envden join [OPTIONS] <server>

Arguments:
  <server>  Server address, e.g. envden.your-tailnet.ts.net

Options:
      --recovery
          Paste a recovery secret key and vault ID
      --recovery-kit <recoveryKit>
          Recovery kit path
      --name <name>
          Device name
      --yes
          Use default preferences
      --telemetry <telemetry>
          Anonymous telemetry (choices: "on", "off") [possible values: on, off]
      --update-check <updateCheck>
          Daily update check (choices: "on", "off") [possible values: on, off]
      --shell <shell>
          Shell notice (choices: "zsh", "bash", "fish", "powershell", "none")
          [possible values: zsh, bash, fish, powershell, none]
      --agent <agent>
          Install the agent skill (choices: "on", "off") [possible values: on,
          off]
      --resume
          Finish a join that was approved while this command wasn't running
  -h, --help
          Display help
