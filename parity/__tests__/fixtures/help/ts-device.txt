Usage: envden device [options] [command]

Add, list, rename and remove devices

Options:
  -h, --help             display help for command

Commands:
  add                    Show a pairing code for a new device
  ls [options]           List devices and the version each last used
  rename <name>          Rename this device
  rm [options] <device>  Remove a device and re-key the vault so it can't read
                         new changes
  help [command]         display help for command
