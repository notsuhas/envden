Keep yours, take the server's, or finish an edited conflict

Usage: envden resolve [OPTIONS] [file]

Arguments:
  [file]  Conflicted env file

Options:
      --json         Print the result as JSON
      --list         List unresolved conflicts
      --repo <repo>  Select a checkout
      --keep-mine    Keep your version
      --take-server  Take the server's version
  -h, --help         Display help
